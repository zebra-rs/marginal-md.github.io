What it does

rust
One markdown engine
A single Rust parser feeds the editor, the preview, PDF export, and the AI context. No second implementation to drift.
native
Native app, not a browser tab
A Rust core in a Tauri 2 shell on the platform webview — no bundled browser runtime to download, update, or keep warm.
ai
AI in the document
Select text, press ⌘K, and the rewrite streams in as an inline diff — accept, refine, or reject. One undo step.
claude code
Claude Code, first class
Your workspace's CLAUDE.md, skills, agents, and commands appear in the sidebar as ordinary markdown, and a built-in terminal runs Claude Code beside them.
files
Plain files, yours
Notes are .md files on your disk — no proprietary format, no forced sync. A licensed install keeps working offline for weeks between checks.

AI that reads the document, not a screenshot of it

The AI receives the same parsed tree the preview renders, so headings, code fences, and front matter arrive structured.

Edit in place with ⌘K

Select a region — or just put the cursor in a block — and describe the change. The rewrite streams in as an inline diff against the original; nothing is applied until you accept.

  • Presets for the common asks: improve, fix grammar, make concise, expand, translate, change tone, continue
  • Accept lands one undo-able edit; Refine reopens the prompt with the result as context
  • “Ask about selection” answers in a side panel without touching the file

Your key, your data

AI runs on your own Anthropic API key. It lives in the OS keychain and is attached to requests inside the Rust process — it never reaches the webview, the logs, or a config file.

  • Document content leaves the machine only when you invoke an AI action
  • Model is configurable; Claude Opus by default
  • AI is never a license gate — the subscription covers the editor
