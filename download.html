Installing

macOS. Open the disk image and drag Marginal into your Applications folder. The build is signed with a Developer ID and notarized by Apple, so it opens without a warning.

Windows. Run the installer. The Windows build is not code-signed yet, so SmartScreen warns the first time you run it: click More info, then Run anyway.

Linux. The AppImage runs from anywhere once it is executable. The .deb and .rpm packages install through your package manager as usual.

First launch

Marginal opens on the Welcome screen. Open a folder to make it your workspace, open a single file, or start a new document. Signing in from Settings ▸ Account starts a 14-day trial of the full app; reading, preview, and export work without signing in at all.

Updates

Marginal checks for a new version a few seconds after launch and says so in the status bar. Nothing downloads until you ask, and every update is signed and verified before it is applied, on all platforms.

The manual has the details: Install Marginal, macOS, Windows, and Linux, and Updates.
