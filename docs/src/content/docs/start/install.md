Marginal runs on macOS 12 or later, Windows 10 or later, and Linux on x86_64
or aarch64. Get the build for your platform from the
[download page](https://marginal.md/download.html).

## macOS

Open the disk image and drag Marginal into your Applications folder. The
build is signed with a Developer ID and notarized by Apple, so it opens
without a warning.

## Windows

Run the installer. The Windows build is not code-signed yet, so SmartScreen
warns the first time you run it: click **More info**, then **Run anyway**.

## Linux

The AppImage runs from anywhere once it is executable (`chmod +x`). The
`.deb` and `.rpm` packages install through your package manager as usual.

Windows and Linux builds are newer than the macOS one and have seen less
real-world use.

## First launch

Marginal opens on the Welcome screen. Open a folder to make it your
workspace, open a single file, or start a new document.
[A tour of the window](../tour/) shows what you are looking at.

Signing in starts a 14-day trial of the full app, with no card. You can
read, preview, and export without signing in; editing needs the trial or a
subscription. See [Account and subscription](../../more/account/).

## Updating

Shortly after launch Marginal checks for a new version and, if there is
one, says so in the status bar. Nothing downloads until you ask. See
[Updates](../../more/updates/).
