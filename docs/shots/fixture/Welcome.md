# Welcome to Marginal

Marginal keeps your notes as plain markdown files on disk. Open a folder and it
becomes your workspace; every file in it is a document you can edit, preview,
print, or hand to the AI.

> [!TIP]
> Press **⌘2** for the split view, **⌘1** for the editor alone, and **⌘3** for
> the preview alone.

## What lives here

- `Meeting notes.md` — a running log with task lists
- `Reading list.md` — a table, some links, a footnote
- `projects/Launch plan.md` — headings to fold, a mermaid diagram, code

## A little of everything

Marginal renders GitHub-flavored markdown: **bold**, _italic_, ~~struck~~,
`inline code`, and [links](https://marginal.md).

| Feature | Where |
|---|---|
| Live preview | the right pane |
| Diagrams | ```` ```mermaid ```` blocks |
| PDF export | File ▸ Print… |
